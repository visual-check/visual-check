visual-check

Proof every story before it ships.

visual-check is an open-source CLI for Storybook. It snapshots every story, compares each with the baseline you approved, and shows which stories moved, by how many pixels, in a visual diff.

Run in your repo
$ npx @visual-check/cli init

It finds your Storybooks, asks a few questions and installs what it needs. MIT licence, no account.

the problem

A one-line change moves forty stories.

A shared token or component sits under dozens of stories. Change one line and every story that uses it can shift. Code review shows the line. Nobody reads the pixels it moved.

Coding agents make it worse: more UI changes, larger diffs, and an agent can't see what it changed.

features

Same pixels on every machine.

A pinned browserThe browser runs in visual-check's own image, pinned by digest. A baseline written on a Mac passes in Linux CI and on Windows.

Baselines in your repoPNG files beside each Storybook, reviewed in the pull request like code. No service, no account.

Affected stories onlyOnly the stories a change can reach. Its own browser driver, and sharding with a consistency check.

Honest with real storiesAnimations at their end state, readiness for fonts and images, flaky snapshots retried and listed.

agent

Your agent can't see the UI. Now it can check it.

init writes an agent skill. Your agent runs visual-check after UI changes, before it says the work is done, and reports which stories moved, with the diff paths.

It never accepts its own changes: no update, no raised tolerance, no disabled story without your OK.

questions

Questions before you run it.

Do I need Docker?

By default, yes: that's how the pixels match everywhere. Without Docker, platform: 'host' uses a local browser, and baselines then only match on the same OS.

I'm on Apple silicon.

It runs linux/amd64 through Rosetta by default, or linux/arm64, which the default tolerance absorbs.

Where do baselines live?

.visual-check/baselines/ beside each Storybook, committed. Only a person running update writes them.

What does it cost?

Nothing. MIT.
