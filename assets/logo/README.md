# visual-check logo

A check printed twice, off register. The two plates are the baseline and the snapshot, and only the overlap is solid ink.

## Files

| File                                              | Use                                                          |
| ------------------------------------------------- | ------------------------------------------------------------ |
| `logo-horizontal.svg`, `logo-horizontal-dark.svg` | Default logo: README headers, site navigation                |
| `logo-vertical.svg`, `logo-vertical-dark.svg`     | Square-ish spaces                                            |
| `wordmark.svg`, `wordmark-dark.svg`               | Where the mark already appears nearby                        |
| `mark.svg`, `mark-dark.svg`                       | Mark alone                                                   |
| `mark-mono.svg`, `mark-mono-white.svg`            | One colour, such as the Storybook toolbar icon               |
| `favicon.svg`                                     | Browser tab; switches with the browser's light or dark theme |
| `favicon-16.png`, `favicon-32.png`                | Favicon fallback for browsers without SVG support            |
| `apple-touch-icon.png`                            | iOS home screen                                              |
| `avatar.png`                                      | GitHub and npm organisation avatar                           |

`-dark` files are for dark backgrounds. All text is outlined, so no font is needed to render them.

## Colours

| Name    | Hex       | Role                      |
| ------- | --------- | ------------------------- |
| Cyan    | `#00B4D8` | First plate               |
| Magenta | `#FF2D87` | Second plate              |
| Ink     | `#15133C` | Overlap and text on light |
| Paper   | `#F4F2FF` | Overlap and text on dark  |

## Type

The wordmark is Bricolage Grotesque Bold (SIL Open Font License).

## Usage

- Keep clear space around the logo at least as wide as half the mark.
- Smallest sizes: mark 16 px, horizontal logo 20 px tall.
- Don't recolour the plates, close the gap between them, or add effects.
